# Android 桌面小工具

適用 Android 8.0 以上的 64 位元裝置（ARM64 或 x86‑64）。1×1 顯示 ChatGPT 或 Claude，2×1 同時顯示兩者。Android 12 以上使用指定的目標格數。

## 安裝與連接

1. 在手機下載 [AI 額度口袋 APK 1.4.6](../downloads/ai-quota-pocket-1.4.6.apk?raw=true) 並安裝。
2. 開啟「額度口袋」，按「登入 ChatGPT」，在 OpenAI 頁面完成授權後返回。也可在右上角的「設定」選擇「ChatGPT 裝置碼登入」，取得代碼後按「複製代碼並開啟登入頁」。
3. 按首頁的「加入小工具」按鈕，在桌面確認新增。也可長按桌面，從小工具清單挑選 1×1 或 2×1。
4. 按「登入 Claude」。初次需下載約 140 MB 並保留至少 450 MiB 空間。Claude Code 檔案下載中斷時可重試續傳。安裝完成後，在官方頁登入並返回。若官方頁顯示授權碼，使用 App 的「貼上 Claude 授權碼」。
5. 如需經由電腦同步，在「設定」的「電腦同步」中選擇「連接私人儀表板」，開啟網站後按「連接這部手機」。

在「設定」的「主畫面小工具」可選自動、只顯示 ChatGPT、只顯示 Claude，或顯示兩者。自動模式在只有一家已連接時建議加入 1×1，兩家都連接或都尚未連接時建議加入 2×1。已加入的 1×1 會更新顯示的服務。要改變桌面上的尺寸，可替換為另一種小工具。

顯示的是各平台已取得期間中最低的剩餘百分比，和網站的「可用額度」一致。沒有資料時顯示 —；資料時間沿用電腦實際讀取時間，背景抓取成功不會把舊記錄偽裝成新用量。

## 更新頻率

Android 使用系統 JobScheduler 約每 15 分鐘更新 Codex；Claude 手機直連約每 30 分鐘讀取，時間會受省電與網路狀態影響。點小工具會安排手動刷新。每張卡顯示當期與每週共用額度中剩餘較少的一項及其重置時間。電腦同步模式仍可透過 Chrome 套件與私人儀表板每 5 分鐘讀取資料。

## 隱私與配對

Codex 使用 [OpenAI 開源 Codex 裝置碼流程](https://github.com/openai/codex/blob/rust-v0.170.0/codex-rs/login/src/device_code_auth.rs) 登入，手機只請求額度資料，登入憑證由 Android Keystore 保護，不傳至儀表板。裝置碼由 OpenAI 官方登入頁驗證，可能需要在 ChatGPT 安全性設定啟用裝置碼登入。這個讀取流程使用 Codex 的服務介面，服務端變更時可能需要更新 APK。

Claude 透過官方 [Claude Code `/usage`](https://code.claude.com/docs/en/commands) 讀取用量。原版程式在私有的 Linux 設定資料夾完成登入並自行保存登入狀態。小工具使用 Claude Code 的非互動 `/usage` 指令讀取額度，並擷取百分比和重置時間。

儀表板配對使用 RSA-OAEP SHA-256 與 AES-GCM 保護唯讀裝置令牌。令牌 90 天後需重新配對，可於網站 `/widget-pair` 解除連接。

## 建置與驗證

安裝 JDK 17、Node.js，以及 Android SDK 的 `platforms;android-35` 和 `build-tools;35.0.0`。將 `ANDROID_HOME` 指向 SDK 目錄，從專案根目錄執行 `node android/build.mjs`。輸出為 `android/dist/ai-quota-pocket-development.apk`。

此建置會產生自己的開發簽章，金鑰留在本機的 `android/dist/`。已安裝公開 APK 的裝置若要測試自建版，請先備份需要保留的設定，再從測試裝置移除簽章不同的舊版。

已完成 Java 編譯、DEX 編譯、APK v2/v3 簽章驗證和配額解析測試。Claude 手機直連目前為測試功能，尚待實機驗證首次安裝、登入與鎖屏排程。

## 1.2 設計與重置資訊
改為三張獨立深色漸層卡片，加入剩餘進度條，低於 25% 顯示琥珀色、低於或等於 10% 顯示警示粉色。每張卡片顯示與所選額度期間對應的重置資訊。具有完整日期及時區時顯示倒數；只有星期或時刻時，保留官方時間，不推算日期。倒數隨小工具刷新而更新，達到重置時間後顯示待確認，不會自行把額度補為 100%。1.1 的連接設定可保留。
